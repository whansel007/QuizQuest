# 2026-10-19

## QuizQuest repo — architecture review
- Adaptive gamified learning platform prototype (quiz app + realtime co-op "World" + game labs). Synthetic demo data only; passwordless "pick a demo user" login.
- Stack: Vue 3 (Vite, `web/`) -> Node 22 `http` server (`server.js`) + Socket.IO. DB = Supabase Postgres OR local JSON file (`data/db.json`) when SUPABASE_URL unset. Optional Gemini for AI drafting/OCR/grading.
- Server-authoritative model everywhere: browser is a "screen", never holds answer keys or decides correctness/rewards.
- Backend `src/quiz/`: api.js (router ~80 routes), store.js (JSON store), adaptive.js, grading.js, rewards.js, economy.js, formats.js, mathexpr.js, generator.js/retrieval.js/validate.js, vision.js, evaluation.js, analytics.js, time.js, seed.js, gemini.js.
- DB mapping in `src/db/schema.js` (collections <-> Supabase tables, jsonb `extra` fallback); `src/db/supabase-store.js` loads all rows at boot, writes back only changed rows every 250ms. Single-instance only.
- Multiplayer: `src/world/world.js` (Socket.IO `/world` namespace, one room per class, token-checked handshake, co-op raid boss + resource nodes). `public/tag` = original Circle Tag, `public/hero-lab` = isolated hero testbed.
- Tests: `node --test` (API/unit/Socket.IO), Playwright browser tests (`npm run test:browser`). AUDIT.md = 7 Oct 2026 audit (60 tests pass).
- Run: `npm install` + `npm run dev` (Vite :5173 proxies /api, /socket.io, /tag, /hero-lab to Node :3000).
