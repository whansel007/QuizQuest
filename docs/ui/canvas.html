Three simple ideas

1. The world

A large map has its own coordinates. The character stays at one position on this map as it moves.

2. The camera

The camera is just two numbers: where the screen should look on the map. It is not a physical object inside the canvas.

3. The canvas

Each frame, code paints the part of the map the camera can see. A hidden canvas can store a small drawing, like a tree, so it can be reused.

What the code is doing

First it moves the character and updates the camera position. Then it shifts the drawing by the camera position and paints the scene. The minus sign means “move the map the opposite way,” which makes it look like the camera moved.

screen position = world position − camera position

In this demo, the tree is drawn once into a hidden canvas. The main scene reuses that little picture many times with drawImage(). The hidden canvas is created only while this page is open; it is not another screen the player sees.
